# sangupta.github.io

Ever wonder what happens when a developer lets their thoughts, code, and occasional ramblings escape into the wild? Well, you're looking at the source code for exactly that: [sangupta.com](https://sangupta.com)!

This repository is where all the magic (and sometimes, the late-night debugging) happens for my personal blog and site. Dive in to see how the sausage is made, or just marvel at the sheer dedication it takes to maintain an online presence since 2006 without succumbing to the allure of panda videos (mostly).

## What's Inside?

You'll find all the juicy bits that power sangupta.com here:

* **Blog Posts**: My unfiltered thoughts on tech, life, and probably why that one CSS property just won't behave.

* **Code Snippets**: Because sometimes, a blog post just isn't complete without a perfectly formed block of code. Or a perfectly broken one, depending on the day.

**Site Pages**: All the other static goodness that holds this digital tapestry together.
